KodVadAll licensing flow: generate a 3072-bit RSA key pair on a trusted vendor machine using `php tools/generate-license-keypair.php /secure/kodvadall-keys`. Keep the private key outside web root and outside Git. Add the public PEM key to the License & Updates page on customer installations. Download activation request JSON. Build a payload with product=KodVadAll, license_id, customer, domain, machine_fingerprint, edition, issued_at, expires_at and features. Sign it using `KD_LICENSE_PRIVATE_KEY=/secure/key.pem php tools/issue-license.php payload.json signed-license.json`. Customer uploads signed JSON. Verification checks RSA-SHA256 signature, product, domain, install fingerprint and expiry. GitHub push webhook remains the automatic update mechanism.
